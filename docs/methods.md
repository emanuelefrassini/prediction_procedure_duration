# Methods and implementation

This page maps the published procedure-duration experiment to its code. For the full scientific design, consult the [journal article](https://doi.org/10.1080/24699322.2025.2466426).

## Input and target

- **Population:** 222 coronary angiography procedures.
- **Input:** one manually annotated clinical workflow phase at each sampled timestamp (14 phase categories).
- **Target:** time remaining until the end of the procedure, represented in seconds.
- **Representation:** `data/X.csv` and `data/Y.csv` are aligned arrays of 222 procedures × 7,573 time positions, with `-1` marking trailing padding.
- **Sampling:** the experiment selects `0::REDUCE_DIM` using intervals of 5, 10, 30, 60 or 120 seconds.

No raw images or video frames are passed to the ETC networks.

## Model implementations

The following are **configured parameters in** [`models/PAPER_ETC.py`](../models/PAPER_ETC.py), which calls the original factories in [`utils/models.py`](../utils/models.py). They should not be confused with a claim of bitwise reproduction of the paper's historical training runs.

| Architecture | Configured capacity | Batch size | Learning rate |
|---|---|---:|---:|
| LSTM | 128 units, dropout 0.1 | 8 | 0.001 |
| LSTM-Attention | 128 units, dropout 0.1 | 8 | 0.001 |
| LSTM-FCN | 256 LSTM units, dropout 0.1, convolutional branch | 4 | 0.001 |
| Transformer | Head size 16, 4 heads, 2 encoder blocks, FF dimension 4 | 2 | 0.001 |
| InceptionTime | 30 filters, depth 8, kernel size 41, residual connections | 2 | 0.0001 |

The ensemble averages InceptionTime and LSTM-FCN predictions with **fixed equal weights**. It introduces no additional fitted parameters.

## Evaluation protocol

1. Repeat the outer three-fold cross-validation for 100 trial indices with repeat-specific random states. Every procedure is assigned to exactly one outer test fold per trial.
2. Select an inner validation sample (20% of the outer training procedures) using only the outer training partition.
3. Normalize valid input phase values using training-only extrema. Preserve padding separately; the LSTM-FCN input branch receives zero-valued padding to match its original `Masking()` layer.
4. Normalize targets using a predetermined 600-second scale. Train using SMAPE with padded timesteps omitted. For the original SMAPE convention, each valid point contributes `100 × |prediction − truth| / (|truth| + |prediction|)` with `0/0` defined as zero.
5. Select/restored model weights using inner validation SMAPE only, not the outer test labels. Maximum 1,000 epochs; early stopping patience 100; reduce learning rate by a factor of 2 after 50 unimproved epochs. Training batches retain fixed order.
6. Produce predictions on the held-out outer test fold. Convert remaining-time outputs back to seconds, then calculate mean absolute error in minutes and SMAPE. Report per-procedure results and their macro average.

The observed metrics and validation split in this maintained implementation need not reproduce the original results exactly. The 2025 paper's reported metrics are cited, not regenerated by tests or summary scripts.

## SMAPE convention

For valid prediction/target pairs, the original convention is

\[
\operatorname{SMAPE}_{100}=\frac{100}{N}\sum_{i=1}^{N}\frac{|\hat y_i-y_i|}{|\hat y_i|+|y_i|}.
\]

The normalization is **0–100%** (not the alternative 0–200% version). The implementation omits padded target positions and defines the `0/0` term as zero. Per-procedure scores are computed before macro aggregation.

## Limitations

- The data originate from a single center; the paper's conclusions are not an external clinical validation.
- Some archived convolutional components use centered (`same`) padding and whole-sequence pooling. Consequently the architecture code is **not guaranteed to be causal** at every prediction instant.
- The training scripts are large experiments, not an optimized inference service or real-time clinical decision support system.
- Architecture-specific/hyperparameter-search scripts under `models/` are retained as research material and may reference original workstation paths. The main experiment entry point is `models/PAPER_ETC.py`.
