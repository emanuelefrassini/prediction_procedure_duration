# Paper figures

`published_60s_results.png` visualizes the aggregate MAE and SMAPE values reported in **Table 2** of [Frassini et al. (2025)](https://doi.org/10.1080/24699322.2025.2466426) at a 60-second sampling interval.

The figure is a reconstruction from published summary values, not an output of a new clinical model run. The original manuscript should be used as the authoritative source for the numerical results and other figures.
