# Anonymized procedure sequences

The two public CSV files provide the numerical inputs and targets for the paper's remaining-time prediction benchmark.

| File | Shape | Description |
|---|---|---|
| `X.csv` | 222 × 7,573 | Sequence of manually annotated clinical workflow phases |
| `Y.csv` | 222 × 7,573 | Remaining procedure duration, in seconds |

Rows correspond to procedures; columns correspond to aligned time positions. A trailing value of `-1` marks padding beyond the available sequence for a given procedure. The files do not contain raw videos.

Run `python scripts/inspect_dataset.py --data-dir data` from the repository root to check dimensions and padding without printing individual rows. The paper experiment imports these files by default. The 5/10/30/60/120-second evaluation intervals are generated by temporal subsampling in [`models/PAPER_ETC.py`](../models/PAPER_ETC.py).

See the [methodology](../docs/methods.md) and [original publication](https://doi.org/10.1080/24699322.2025.2466426).
